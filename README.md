# 空島事記（Islog）

完成自己訂的生活小事，換到方塊素材，蓋出屬於自己的空中花園島。Android 離線養成遊戲，使用 Godot 4（GDScript，2D 等角視角）。

企劃書：[docs/PLAN.md](docs/PLAN.md)

## 目前版本：v0.6.0（開發中，分支 notify-v0.6.0）

v0.1.0 核心原型：
- 事件新增、完成、刪除（完成的事件可按「再一次」重新加入）
- 完成事件拿 3 個隨機素材（土、水、石、沙），每天前 10 件給素材
- 一座 10×10×10 的島：選素材點格子放置，「移除」模式點方塊退回素材
- 等角視角：拖曳平移、滾輪／雙指縮放、旋轉 90 度、左側切換樓層
- 本機存檔（`user://save.json` 與 `user://islands/island_0.json`）

v0.2.0 新增：
- 植物：有素材的事件 30% 掉落，每天第一件必掉；12 種植物各自種在對應的方塊上（「植物」工具）
- 四種基本動物：綿羊（土）、小魚（水）、蜥蜴（石）、寄居蟹（沙），完成事件時一次來一隻，同一種最多兩隻，在棲地上漫步
- 棲地消失時動物換位置；完全沒有棲地會冒問號，一天後離開
- 褪色與恢復：整天沒完成事件累積 2 天開始褪色、5 天全灰，動物跟著減少；之後每天完成事件恢復 1/3

v0.2.1 新增（v0.3.0 規劃中的功能，先做）：
- 子事件：事件按「子事件」展開後新增；子事件給 2 個素材並計 1 件，母事件給 3 + 自己打勾的子事件數
- 子事件全部完成時母事件自動完成；直接完成母事件時剩下的子事件一起打勾，但不計件、不給素材
- 「再一次」會連同子事件一起重新加入

v0.3.0 新增：
- 素材 2 換 1：點上方的素材數量開啟交換視窗
- 事件回顧（「回顧」分頁）：累計件數、連續照顧天數、最常做的事；月曆點日期看當天；時間軸列出每天完成的事件、素材、植物與來訪動物
- 棲地條件與 6 種特殊動物：兔子（附近有灌木）、柯基（附近至少 5 格露天的土）、烏龜（附近有沙）、鴨子（附近有土）、山羊（附近石頭疊到 3 層）、螃蟹（附近有水）
- 圖鑑：來過的動物顯示圖案與第一次來訪日期，還沒來的只顯示剪影；出現條件不寫出來，新手引導只說明每種動物喜歡的環境不同；新動物優先來訪
- 稀有毛色：除了烏龜，每種動物來訪時偶爾（10%）是另一種顏色，例如黑毛白臉的綿羊、三色柯基、綠頭鴨；圖鑑算同一格
- 拍照模式：隱藏介面與格線，加上日期浮水印，儲存到手機的「圖片/Islog」資料夾
- 新手引導：柯基帶路，畫面變暗、只亮出要按的地方並有跳動的箭頭；灰色的方塊 → 新增事件 → 完成 → 放方塊（島長出顏色）→ 種花 → 綿羊來訪 → 圖鑑 → 鏡頭拉遠；可略過
- 情境提示：第一次達到每日上限、第一次褪色、快滿 100 件時各提示一次

v0.3.1 新增（v1.0.0 規劃中的功能，先做）：
- 多島與封存：每完成 100 件解鎖一座新島；「我的島」可以建立新島或把收起來的島拿出來，收起來的島時間停止、不會褪色
- 自訂方塊：島嶼頁「自訂」→「＋ 設計」，選基礎類型後用 8×8 像素畫頂面與側面（按住拖曳上色、整面填色、回到起點）；功能跟著基礎類型
- 我的方塊：按「製作」消耗 1 個基礎素材做出一個；設計格一開始 2 格，每完成 30 件多一格（暫定）

v0.4.0 新增（美術改版）：
- 手帳風格：背景是點點紙張，介面改成圓角卡片與線條圖示（樓層、鏡頭、圖鑑、拍照、我的島），素材用小方塊表示，今日素材改成十顆點
- 方塊加描邊、草皮、土粒、石紋、沙粒、水的反光；動物和植物畫大一點
- 晝夜：依手機時間在清晨、白天、黃昏、夜晚之間漸變，紙上畫著太陽、月亮、星星；夜晚島變暗、植物旁有螢火蟲，綿羊、兔子、柯基、山羊、蜥蜴睡覺不走動，介面換成深藍色
- 事件頁：柯基依時段打招呼，左邊的圓圈打勾完成，「子事件／刪除」收進「⋯」，點標題展開子事件；完成的事件用小方塊顯示拿到的素材

v0.5.0 新增（日曆功能）：
- 事件可以設定日期、時間與重複（每天、每週幾、每月、每隔幾天）：輸入列旁的時鐘按鈕，或已經有的事件按「⋯」→「設定時間與重複」
- 事件頁分成「今天／之前沒做完／明天／之後」；今天有時間的事件排在前面；之前沒做完的事件不扣東西，可以「改到今天」
- 重複事件完成後自動排好下一次（子事件一起帶過去），準時完成會累積「連續 N 次」；可以「跳過這一次」
- 回顧頁的月曆標出之後預定的日子（數字旁的點），點日期可以看到那天預定的事，重複事件也會推算出來

v0.6.0 新增（提醒通知）：
- 事件提醒：設定時間時選「準時／提前 10 分鐘／提前 1 小時／前一天」，沒指定時間的事件在當天早上 9 點提醒
- 每日小提醒：那天還沒完成任何事時，柯基在玩家選的時間提醒一次；第一次完成事件後會問要不要開
- 褪色預告：島快開始褪色的前一晚提醒（預設開）
- 安靜時段：預設 23:00–08:00，每日小提醒和褪色預告延到安靜時段結束
- 設定在「回顧 → 通知」；Android 13 以上第一次開啟時會請手機允許通知
- Android 通知外掛在 `android_plugin/`（Java），CI 用 Gradle 建置後放進 `addons/islog_notify/bin/`，匯出改用 Gradle 建置

開發中（v1.0.0 前完成）：
- 帳號與備份：回顧頁「帳號與備份」綁定帳號後自動備份，換新手機時還原；兩邊都有進度時讓玩家選一份。目前電腦版接的是測試用假雲端，手機版要等接上 Google Play 遊戲服務後才能使用

## 開發

需要 [Godot 4.7](https://godotengine.org/download)（標準版，非 .NET）。

```bash
# 用編輯器開啟
godot --editor --path .

# 執行遊戲
godot --path .

# 核心邏輯測試
godot --headless --path . -s res://tests/run_tests.gd

# UI 冒煙測試（模擬點擊與拖曳）
godot --headless --path . -s res://tests/ui_smoke.gd

# 用示範資料截圖（輸出到指定資料夾）
godot --path . -s res://tests/screenshot.gd -- ./shots
```

## Android 建置（GitHub Actions）

每次推到 `main`、推 `v*` tag 或手動執行 workflow，[Android build](.github/workflows/android.yml) 會跑測試並匯出 debug APK。

**下載**：到 [Releases](https://github.com/corgi8cm/IsLog/releases) 下載 APK，直接在手機上安裝（需允許「安裝未知來源應用程式」）。

- **最新測試版**（[`latest`](https://github.com/corgi8cm/IsLog/releases/tag/latest)）：`main` 每次建置都會覆蓋更新。
- **版本 Release**：推 `v*` tag（例如 `v0.1.1`）時建立，APK 附在該版本底下。
- 每次建置的 APK 也會保留在 Actions 的 Artifacts 30 天。

- `version/name` 取自 `project.godot` 的 `config/version`，`version/code` 用 workflow 的執行編號，新版可以直接覆蓋安裝。
- 簽章：repo secret `ANDROID_DEBUG_KEYSTORE_BASE64`（debug keystore 的 base64，alias `androiddebugkey`、密碼 `android`）。
  沒設定時每次會用臨時簽章，手機上要先解除安裝舊版才能裝新版。

## 專案結構

```
scripts/core/   純邏輯（素材、玩家資料、島嶼、等角座標），不依賴畫面
scripts/game.gd 全域狀態 Autoload（Game）：串接邏輯、存檔、發出 changed 訊號
scripts/cloud/  帳號綁定與雲端備份（服務介面、測試用假雲端、同步流程）
scripts/ui/     畫面（主畫面、事件頁、島嶼頁、等角繪製）
scenes/         場景
tests/          測試與開發工具腳本
docs/           企劃
```
